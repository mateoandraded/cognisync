# Prototype

Navigable, non-functional prototype used to validate screens and window flow with the client (midterm SRS, Appendix B). Synthetic data only. The UI text is in Spanish (es-EC), as in the product.

| File | Content |
|---|---|
| `web.html` | Web application, screens W01 to W10. Open it in a browser and navigate with the links, or add `#login`, `#pacientes`, `#nuevo-paciente`, `#expediente`, `#citas`, `#nueva-nota`, `#revision`, `#historial`, `#evolucion`, `#usuarios`. |
| `mobile.html` | Mobile application, screens M01 to M04 (`#hoy`, `#paciente`, `#nota`, `#revisar`). Best viewed at 390 px wide. |
| `tokens.css`, `base.css` | Design tokens (palette, type, spacing) and base rules shared by both files. |

Layout references: Mobbin screens of Heidi, Motion, Sora, Lyssna and Hotjar. Screenshots for the SRS are in `docs/srs/figures/prototype/`.
