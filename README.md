# CogniSync

SaaS platform for mental-health clinics: digital patient records, post-session notes captured by text, voice or photo and structured by AI into SOAP/DAP, symptom-evolution charts and dropout alerts. Software Engineering I, ESPOL, PAO 2026-2. Client: Ing. Fabrizzio Ontaneda.

**Try the prototype:** https://mateoandraded.github.io/cognisync/

| Folder | Content |
|---|---|
| `/` (`index.html`, `web.html`, `mobile.html`) | Navigable prototype of the web and mobile applications. Synthetic data; portraits from randomuser.me. See [PROTOTYPE.md](PROTOTYPE.md). |
| [`elicitation/`](elicitation/README.md) | Evidence of the requirements elicitation techniques: client requirements, open questions, refinement minutes, first user-story draft. |

Development, backlog and the full SRS live in the team's Azure DevOps project. This repository is the public mirror required by the course.
